# Cyber Audio Assets License & Provenance

All sound assets contained in this directory (`Resources/Sounds/`) are license-clean under Creative Commons Zero v1.0 Universal (CC0 1.0) and the Public Domain:
- `purr_loop.wav`: Sourced from the Public Domain acoustic recording of a real domestic cat ("Whiskers") purring while being petted (recorded by Adam Cuerden, released into the Public Domain), prepared with seamless equal-power loop crossfade and 22,050 Hz Mono mastering.
- State & agent SFX: Synthesized specifically for **Bitz the Cyber Cat** using custom waveform generation scripts and dedicated to the Public Domain under CC0.
- Companion archetype reaction SFX: Procedurally synthesized via `Scripts/generate_archetype_sounds.py` for each companion archetype in the multi-mascot roster (Issue #150) using mathematical waveform generators (sub-bass, FM synthesis, harmonic ring modulation, stepper motor pulses) and dedicated to the Public Domain under CC0.
