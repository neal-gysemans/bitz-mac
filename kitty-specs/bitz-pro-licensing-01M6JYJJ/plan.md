# Implementation Plan: Bitz Pro Feature Tiering & Backendless License Architecture

**Branch**: `feat/issue-117-bitz-pro-licensing` | **Date**: 2026-11-04 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/kitty-specs/bitz-pro-licensing-01M6JYJJ/spec.md` (Tracks GitHub issue #117, refs #117, Closes #117)

## 1. Summary

Transition Bitz to a dual-tier companion model (**Free** vs. **Pro**) with a backendless, offline-first cryptographic licensing architecture. 

The Free tier remains a 100% complete, uncompromised desktop companion for beta testers and general developers, featuring Bitz the Cyber Cat with full emotional PTS states, drag-and-snap windowing, hold-to-pet interactions, single AI coding agent monitoring (Claude Code or Antigravity), standard telemetry, and cyber SFX. 

The Pro tier unlocks cosmetic customization and power tools (Mascot Roster #30, Theme/Visor Studio #28, Multi-Agent Swarm, Meeting Recorder #43, and Deep Telemetry). Licenses are validated purely offline using Apple's native `CryptoKit` (`Curve25519.Signing.PublicKey` Ed25519) and persisted securely in macOS `Keychain`. Zero cloud backend servers, zero databases, and zero user accounts or passwords.

## 4. Architectural & Design Decisions

### 4.1 Token Structure & Cryptographic Contract
License keys follow a structured, tamper-evident compact format:
```
BITZ1.<base64url_payload>.<base64url_ed25519_signature>
```
1. **Header**: `BITZ1` identifies version 1 of the Bitz licensing scheme.
2. **Payload** (JSON encoded in UTF-8, then Base64URL-encoded):
   ```json
   {
     "tier": "pro",
     "license_id": "BTZ-2026-X89K-912A",
     "issued_at": 1730712000,
     "expires_at": null
   }
   ```
   *(Note: `expires_at: null` represents a lifetime/perpetual license; a Unix timestamp represents an active subscription or beta access grant).*
3. **Signature**: Ed25519 64-byte signature generated by the Merchant of Record / Bitz release signing key over the raw ASCII bytes of `"BITZ1.<base64url_payload>"`.
4. **Validation in App**:
   ```swift
   let signature = try Curve25519.Signing.PublicKey(rawRepresentation: bitzPublicKeyData)
   let signedData = Data("BITZ1.\(encodedPayload)".utf8)
   guard publicKey.isValidSignature(signatureData, for: signedData) else {
       throw LicensingError.invalidSignature
   }
   ```
5. **Zero Backend**: Verification is 100% local, instantaneous, and immune to internet outages or server downtime.

### 4.2 Storage Protocol & macOS Keychain
To prevent coupling domain logic to the OS Keychain and to allow 100% deterministic unit testing in CI, storage is abstracted:
```swift
public protocol LicenseStorageProtocol: Sendable {
    func loadLicenseToken() -> String?
    func saveLicenseToken(_ token: String) throws
    func deleteLicenseToken() throws
}
```
- **Production (`KeychainLicenseStorage`)**: Stores the raw verified token string under `service: "com.akramks.bitz.licensing"`, `account: "active_license"`, with `kSecAttrAccessibleAfterFirstUnlock`.
- **Test (`MockLicenseStorage`)**: Thread-safe in-memory or suite `UserDefaults` dictionary with zero interaction with the OS keychain.

### 4.4 In-App Settings Experience (`BitzProSettingsTabView.swift`)
1. **Tier Status Card**:
   - Free tier: Displays "Current Tier: Free" with a subtle robot icon, a warm badge explaining that the free companion is fully featured, an input text field to enter a license key, and an "Upgrade to Pro" link button opening `https://bitz.sh` / Polar store.
   - Pro tier: Displays "Current Tier: Bitz Pro" with an animated holographic gradient badge, active License ID, and a "Deactivate / Transfer" button.
2. **Pro Perks Highlights**:
   - Visual preview cards for upcoming Pro capabilities: Multi-Mascot Roster (#30), Theme & Visor Studio (#28), Multi-Agent Swarm, Meeting Assistant (#43), and Deep Telemetry.
3. **Graceful Gating Component (`ProBadgeView` & `ProFeatureGate`)**:
   - Reusable UI component that renders a small cyan-neon `PRO` capsule badge next to locked controls.
   - Non-intrusive popover explaining the feature when clicked, with zero blocking modals.

## 6. Implementation Concern Map (For Co-Developers & Agents)

To ensure smooth collaboration between developers and AI agents:

- **Concern 1: Cryptographic Engine & Models (`LicensingModels.swift`, `LicensingService.swift`)**
  - Defines the mathematical contract, Base64URL decoding, and Ed25519 signature verification.
  - Generates embedded public key constant and sample dev keys for offline testing.
- **Concern 2: Storage & Persistence (`KeychainLicenseStorage.swift`)**
  - Isolates macOS Security APIs.
  - Provides thread-safe mock storage for tests.
- **Concern 3: Settings UI & Gating Components (`BitzProSettingsTabView.swift`, `ProBadgeView.swift`)**
  - Implements the presentation layer in SwiftUI matching the existing Cyberpunk HUD design language.
  - Connects to `SettingsWindowManager` with 0 CPU overhead when window is closed.
- **Concern 4: Documentation & Key Generation Tooling (`docs/LICENSING.md`)**
  - Explains key generation script/instructions so the repo owner can mint and test real keys.
